# Write a recipe: trusted JavaScript in .knomit/recipes/<name>.js, run by a do: run trigger; it may exec programs, is read from the tip of main, and ends with {status, message?, id?}

A recipe is the trusted tier of trigger code: JavaScript that may start programs with `knomit.exec`. A script cannot.

**Where it lives.** `.knomit/recipes/<name>.js`, the name in lowercase kebab-case. For each fire knomit resolves the name in this order: the file at the tip of the repo's consensus (main) branch, else `<home>/recipes/<name>.js` on this machine, else the fire is an unbound no-op. A recipe on an agent branch does not run until it is merged. A broken recipe on main is a `recipe-error`; knomit does not fall back to the machine's copy.

**How it starts.** A trigger with `do: run` and `recipe: <name>` (from the mission template):

```yaml
      - name: wake
        on: learn
        match: "inbox/{agent}/working/**"
        do: run
        recipe: work-task
```

The fire returns at once with a run id; the recipe's result is a second fire-log row with the same id.

**The file.**
- An optional header on the FIRST line, parsed as JSON: `// knomit: {"concurrent": 1, "jitter_ms": 500, "timeout_ms": 1800000}`. Defaults: 1 concurrent run of the recipe per repo on this knomit instance (two repos on one machine each get their own slots), no jitter, 30 minutes. An unknown field or a bad value makes the recipe a `recipe-error`.
- The body runs in the same sandbox as a script, with `exec` added to the host object.
- Its last expression is its result: an object `{status, message?, id?}` with `status` one of `done`, `spawned`, `delivered`, `unreachable`, `error`. Anything else is an invalid result.

**Samples.** `.knomit/artifacts/recipes/claude-session.js` in this repo (`kb/reference/recipes/claude-session/`) starts one headless Claude Code session per fire, with the repo's knomit server as its MCP server; read it with `knomit_explain` on its path and put it in `.knomit/recipes/` in your repo, or in `<home>/recipes/`. The mission template's `work-task.js` (`kb/templates/mission/files/recipes/work-task/`) is a fuller one.

Trust: whoever can change the consensus branch decides what recipes run.
