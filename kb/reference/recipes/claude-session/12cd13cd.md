# claude-session.js: a sample recipe that starts one headless Claude Code session per fire, with this repo's knomit server as its MCP server and the task passed by path

File: `.knomit/artifacts/recipes/claude-session.js`. A standalone recipe, not part of a template.

**What it does.** Each fire runs `claude --model sonnet --mcp-config <mcp.config> --allowedTools <mcp.tools> -p <prompt>`. The prompt names the firing fact by path (`task_path`), says to read it with `knomit_explain`, do it and record the result in knomit, and hands the session a `trace` (`Knomit-Cause`, `Knomit-Run`, and `Knomit-Trace` when the firing change's trace is a plain id) to pass on every knomit write. Its result is `{status: "done"}` on exit 0, else `{status: "error"}`.

knomit gives a recipe `task_path`, `mcp` (`config`: this repo's MCP configuration with the `kb` bridge, `tools`: `mcp__<key>`) and `run` (`id`); `kb` reaches this knomit through the `KNOMIT_SERVER` knomit sets.

**Header:** `// knomit: {"concurrent": 1, "timeout_ms": 1800000}`.

**Install it** in one of two places: commit it to `.knomit/recipes/claude-session.js` on your repo's consensus branch, or copy it to `<home>/recipes/claude-session.js` on the machine. Start it with a trigger `do: run`, `recipe: claude-session` (`kb/howto/recipes/write-recipe/`).
