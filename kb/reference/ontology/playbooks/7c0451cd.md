# knomit-playbooks .knomit/ontology.yaml: topics howto, patterns, reference, gotchas, templates; templates has learn_dedup off and the context keys template and part, reference has the context key part

File: `.knomit/ontology.yaml`, this knowledge base's own ontology, id `knomit-playbooks`.

| topic | holds | context |
|---|---|---|
| `howto` | step-by-step instructions for one task | none |
| `patterns` | designs built from knomit's primitives | none |
| `reference` | what each knob does; one fact per file under `.knomit/` that is not part of a template | `part`: enum `file`, `skill` |
| `gotchas` | sharp edges | none |
| `templates` | per template: one `part: template` fact, one `part: file` fact per file, one `part: edit` fact per change to make | `template`: string, required, `^[a-z][a-z0-9-]*$`; `part`: enum `template`, `file`, `edit`, required |

`templates` has `learn_dedup: off`: the file facts of different templates describe look-alike files (four `ontology.yaml`, four `README.md`).

Find one template's facts with `context: {"template": "<name>"}`, every template with `path: "kb/templates/"` and `context: {"part": "template"}`.
