# Fleet edit, hosting: put the fleet repository where every instance can clone it and push its agent branch, and decide who merges agent branches into main, since that merge accepts a member

Create the fleet repository on a git host every instance of the fleet can reach, such as a private GitHub repository, with mode `initialize` and the `fleet` template (`kb/templates/fleet/`), and merge the creating instance's agent branch into main. Each instance then clones it and pushes its own agent branch there.

Each instance joins with `knomit fleet register <url>` (REST `PUT /api/v1/fleet {"url": "<url>"}`): knomit clones the repo, refuses it unless its ontology id is `fleet`, writes the instance's member record on its agent branch and pushes it. A person accepts the instance by merging that agent branch into the fleet repository's main branch. Decide who does that merge.
