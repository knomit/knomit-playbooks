# fleet README.md: the fleet repository's README: one member record per agent, joined on an agent branch and accepted by a merge into main; lands at README.md

File: `.knomit/templates/fleet/README.md`. Lands at `README.md` in the new repo.

It says the repo is the source of truth for one knomit fleet: each agent's member record is a fact at `kb/members/<agent-id>/<id>.md` with its state (`active`, `left` or `revoked`), its current signing key, its host and branch; records are never deleted. An instance joins by writing its own record on its agent branch, and a person accepts it by merging that branch into `main`. Everything under `.knomit/` changes through git only. Name the fleet and who accepts members in it (`kb/templates/fleet/use/readme/`).
