# The fleet template is knomit's built-in fleet preset (ontology id fleet): one member record per agent under kb/members/<agent-id>/; pushed to a git host and joined with knomit fleet register, never created as a local repo

Template folder: `.knomit/templates/fleet/`.

**What it is for.** The fleet repository, the source of truth for a knomit fleet. Its ontology is knomit's embedded `fleet` preset: one topic, `members`, one member record per agent, never deleted.

**Its files** (one fact each under `kb/templates/fleet/files/`): `README.md` and `.knomit/ontology.yaml`, landing at the same paths in the new repo.

**What to edit** (under `kb/templates/fleet/use/`): keep the id `fleet`; hosting and who accepts members; the README.

**How to use it.** Write both files to a git repository and push it where every instance of the fleet can reach it. Each instance joins with `knomit fleet register <url>` (REST `PUT /api/v1/fleet {"url": "<url>"}`), which writes its member record on its agent branch; a person accepts it by merging that branch into main. Never create it as a local repo: knomit treats any mounted repo with the id `fleet` as the instance's fleet.
