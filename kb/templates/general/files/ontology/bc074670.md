# general .knomit/ontology.yaml: knomit's embedded default preset byte for byte (id general), thirteen top-level subject topics with child categories, no validations or triggers; lands at .knomit/ontology.yaml

File: `.knomit/templates/general/.knomit/ontology.yaml`. Lands at `.knomit/ontology.yaml` in the new repo.

Byte for byte knomit's embedded `default` preset, `internal/fact/ontology_default.yaml` (id `general`, name "General Knowledge"). Its top-level topics are people, technology, science, society, culture, geography, history, health, philosophy, religion, business, reference and meta, each with child categories. It declares no validations, triggers, context, skills or recipes.

It is the template's only file under `.knomit/`, so a repo created from the template holds this ontology and the README. With the id `general`, knomit upgrades a stored ontology that is a strict subset of a newer embedded preset when the repo opens.
