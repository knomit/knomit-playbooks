# Mission edit, the session: .knomit/recipes/work-task.js starts the agent each copy runs in; set MAX_BUDGET_USD before the first run, and change MODEL or the claude argv to match the agent you run

Edit `.knomit/recipes/work-task.js` before the first run:

- `MAX_BUDGET_USD` ("5"): the most one session may spend, passed as `--max-budget-usd`.
- `MODEL` ("sonnet"): the model the session runs.
- The allowed tools (`mcp__<KEY>`, `WebFetch`, `WebSearch`) and the `claude` argv: change them for another harness. Keep the task out of argv and the prompt; the session reads it through knomit by path.
- `KEY` ("knomit"): the MCP server key the session sees.

`mktemp` and `rm` must be on the PATH knomit runs with. knomit runs a recipe from the tip of the repo's consensus branch, so an edit takes effect once it is merged there. README section "The session".
