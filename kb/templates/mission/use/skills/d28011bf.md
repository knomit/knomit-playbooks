# Mission edit, the skills: rewrite post-task and work-task for the work this mission does, and keep every JSON call skeleton in them

Each mission has its own skills. Rewrite `.knomit/skills/post-task/SKILL.md` and `.knomit/skills/work-task/SKILL.md` for this mission's work: what a task body says, what a session does with it, where results go.

Keep:
- the frontmatter `name` equal to the folder name;
- every call skeleton, the fenced ```` ```json knomit_learn ```` blocks with the binding, `moment_name`, `facts`, `retract` and `trace`: a session that knows only a tool's name makes the call right the first time from them;
- the queue loop in `work-task` (take every copy, stop when `working/` is empty) and the trace on every write.

knomit serves skills from the tip of the consensus branch: an edit is served once it is merged there. README section "Skills".
