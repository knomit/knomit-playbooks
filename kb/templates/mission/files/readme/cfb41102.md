# mission README.md: how the mission repo works (hosting, timing rule, queue, session, trace, annotations, frames); lands at README.md

File: `.knomit/templates/mission/README.md`. Lands at `README.md` in the new repo.

The mission repo's manual. Read it before you edit any other file of the template. Its sections:

- **Create it**: create the repo from the template (mode `template`, `kb repo create --template`, or the wizard's **From a template**); a forge-hosted repo uses mode `initialize`.
- **Knomit-hosted** and **GitHub-hosted**: the two ways to host the repo, and what `consensus: auto` and `sync` cost on a forge.
- **Set it once and forget**: the repo settings `consensus`, `conflicts` and `sync`.
- **Conflicts**: how a path both sides changed is merged and recorded.
- **Two ways to take a task**: pattern 1, claim / wait / take (`claims.js`), and pattern 2, host-awarded (`awards.js`).
- **The timing rule**: how the claim window X (`WINDOW_SECONDS`) follows from the sync settings.
- **The queue**: `inbox/<agent-id>/working/` and `active/`, the lease, the ack.
- **Capacity and parallelism**: `CAPACITY` against the recipe's `concurrent`.
- **The session**: what `work-task.js` starts and with which tools.
- **The trace**: `Knomit-Trace`, `Mission-Task`, `Knomit-Run`.
- **Re-offering**, **The target knowledge base**, **Annotations**, **Frames**, **Skills**, **Editing the template**.

**Frames** documents the `frames/` topic: a mission's thinking-process nodes (`kind: pragmatic`, `type: frame`), writable only from a knomit build that has the `frame` type. It states that a validation refuses any non-frame under `frames/`; that `learn_dedup: off` is a topic setting (without it two sibling frames merge, an observation folds into a frame, an incoming frame can settle a nearby hypothesis) and the type alone does not prevent that; that a frame has no `status` key; and that a frame's parents are the frames it refs (any ref whose target is a frame), and a frame may have several. The README does not say what an abandoned frame is; by the user's ruling of 2026-10-28 a retracted frame is the abandoned one.
