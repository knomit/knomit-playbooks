# mission work-task skill: drain this machine's queue, one copy at a time, each task in a knowledge-base experiment, then acknowledge; lands at .knomit/skills/work-task/SKILL.md

File: `.knomit/templates/mission/.knomit/skills/work-task/SKILL.md`. Lands at `.knomit/skills/work-task/SKILL.md` in the new repo.

The skill the session that `work-task.js` starts follows (`knomit_skill` with name `work-task`). The session takes every copy in `inbox/<agent-id>/working/`, one at a time, and stops only when a query of `working/` comes back empty after its last ack.

For each copy: take it with one move into `active/`; bind the knowledge base the task names (a second handle); open a `knomit_experiment` named after the task id in kebab-case, do the work there, commit it (or roll it back and acknowledge the task as failed); acknowledge with one move (write `acks/<task-id>/`, delete the `active/` copy). It passes the trace on every write, and updates a shared fact only when its task names that fact by path.

Its "Call shapes" section has a JSON skeleton for every knomit call the session makes; keep them when you rewrite the skill.
